Motor de Validación y Conversión de Autómatas (AFD/AFND)

Programa de consola en Python 3, sin dependencias externas. Elaborado por Gerber Perez y Marco Donadio para el curso de Lenguajes Formales y Autómatas (Facultad de Ingeniería, URL).

Permite crear, cargar, validar, simular y convertir Autómatas Finitos Deterministas (AFD) y No Deterministas (AFND), definidos formalmente como la quintupla M=(Q,Σ,δ,q0,F).
